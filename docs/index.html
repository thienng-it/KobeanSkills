KobeanSkills Documentation

Universal engineering skill distribution and multi-role agent orchestration system natively supporting Gemini CLI & Antigravity, Claude CLI (Claude Code), and Codex CLI.

Quick Start (Zero Cloning Required)

Install KobeanSkills into any existing repository in seconds using your preferred method:

Run inside any repository. Works with Bun (~50ms instant boot) or Node/npx:

# With Bun (fastest):
bunx kobean-skills init

# Or with Node/npx:
npx kobean-skills init

Pure shell command for Python, Go, Rust, or any environment without Node installed:

curl -fsSL https://raw.githubusercontent.com/thienng-it/KobeanSkills/main/setup.sh | bash

Run in an isolated container sandbox with companion tools (bd, betterleaks, osv-scanner) pre-baked:

docker run --rm -v "$(pwd):/workspace" ghcr.io/thienng-it/kobean-skills:latest kobean init

If you already cloned KobeanSkills locally, initialize any project directory:

cd /path/to/any-repo
~/Developer/KobeanSkills/init.sh

End-to-End Feature Pipeline

When you ask to build a new feature, kb-router chains the following autonomous pipeline:

1
Requirements & Security (kb-spec)
Enforces the Ponytail Ultra gate ("should this exist?"), asks Socratic clarifying questions, and produces spec.md and STRIDE threats.md.
2
Architecture & Contracts (kb-plan)
Designs OpenAPI/Zod interfaces, PostgreSQL schemas, and generates the task dependency graph in .beads/ using bd.
3
Autonomous Implementation (kb-build)
Fetches ready tasks from Beads, writes failing tests first (Red), implements the minimal code (Green), and obeys Ponytail code economy.
4
Verification & Quality Gates (kb-review)
Hard completion gates: betterleaks secret scan, Trail of Bits AppSec, Core Web Vitals, WCAG 2.2 accessibility, and test suites.
5
Documentation & Delivery (kb-ship)
Writes Diátaxis documentation, SemVer CHANGELOG.md, checks CI safety, and provides a rollback runbook.

Developer Playbooks (Copy-Paste Prompts)

1. Feature Engineering

Use when creating new functionality or multi-file capabilities:

Use kb-router to build an invitation system where admins can invite teammates via email with expiring tokens.

2. UI/UX Craft & Art Direction

Use for product surfaces (default) or landing pages (bold mode):

# Standard Dashboard / Product Surface (Impeccable craft):
Use kb-ui to build the user analytics dashboard with complete loading, empty, and error states.

# Bold Art Direction (Taste-Skill mode for landing pages & brand sites):
Use kb-ui in bold mode to build the product landing page.

3. Root-Cause Debugging

The agent reproduces first, traces callers, and writes a failing regression test before writing a fix:

Use kb-debug to investigate this error:
[Paste error log, stack trace, or failing test output]

4. Pre-PR Review & Security Gate

Audits current git changes for secrets, security bugs, bloat, and broken tests:

Use kb-review to audit my current diff and check security.

5. Technical Debt & Simplification

Deletes dead code and simplifies structure while proving zero behavior change:

Use kb-build with the refactorer role to clean up and simplify src/server/auth.

6. Unfamiliar Codebase Onboarding

Parses codebase AST into a knowledge map and generates CONTEXT.md:

Use kb-router to onboard this repository.

CLI Helper Commands

npx kobean-skills init
Initializes self-contained .kobean/ and wires agent discovery in the current repository.
npx kobean-skills doctor
Verifies whether companion CLIs (bd, betterleaks, graphify, osv-scanner) are installed.
npx kobean-skills guide
Outputs the complete developer playbook and prompt cheatsheet directly in your terminal.
npx kobean-skills install
Registers KobeanSkills machine-wide in ~/.gemini/config, ~/.claude, and ~/.codex.

Engineering Doctrine & Precedence

  • Precedence Hierarchy: User Prompt > constitution.md > doctrine.md > Role Contract > Skill Runbook.
  • Single Task State: Beads (.beads/) is the exclusive source of truth. Never create tasks.md or progress.md.
  • Ponytail Economy: Write the smallest complete diff. Reuse project helpers > standard library > installed packages. Zero unrequested wrappers.
  • UI Hard Bans: No neon purple/blue AI-slop gradients, no 3-card marketing clichés, no missing :focus-visible or broken image placeholders.
  • Hard Completion Gates: Zero secrets (betterleaks), zero unmitigated CRITICAL AppSec findings, and 100% passing test suites.
