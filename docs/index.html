Zero-Clone Quick Start

Install KobeanSkills into any existing repository or brand-new folder in seconds:

Blazing fast instant boot for developers using Bun:

terminal — bunx
bunx kobean-skills init

Universal setup for Node.js environments (pre-installed out-of-the-box):

terminal — npx
npx kobean-skills init

Pure shell command for Python, Go, Rust, or minimal environments without Node/Bun installed:

terminal — bash
curl -fsSL https://raw.githubusercontent.com/thienng-it/KobeanSkills/main/setup.sh | bash

Run in an isolated container sandbox with companion tools (bd, betterleaks, osv-scanner) pre-baked:

terminal — docker
docker run --rm -v "$(pwd):/workspace" ghcr.io/thienng-it/kobean-skills:latest kobean init

End-to-End Feature Pipeline

When you ask to build a feature, kb-router autonomously choreographs this continuous 5-stage engineering lifecycle:

1
Requirements & Threat Modeling kb-spec · po · threat-modeler
Runs Ponytail Ultra existence check ("should this exist?"), conducts Socratic clarification, and produces spec.md and STRIDE threats.md.
2
Architecture & Contract Design kb-plan · architect · api-designer
Designs type-safe OpenAPI/Zod interfaces, normalized PostgreSQL schemas, and builds the task dependency graph in .beads/ using bd.
3
Autonomous Implementation (TDD) kb-build · backend · frontend · devops
Pulls ready tasks from Beads, executes Red-Green-Refactor testing, and writes the minimal clean change obeying Ponytail code economy.
4
Differential Review & Security Gates kb-review · security · qa · reviewer
Hard completion gates: betterleaks secret scan, Trail of Bits false-positive gate, Core Web Vitals, WCAG 2.2 accessibility, and test suites.
5
Documentation & Release Delivery kb-ship · tech-writer · release-manager
Compiles Diátaxis documentation, SemVer CHANGELOG.md, checks CI pipeline integrity, and prepares a rollback runbook.

CLI Helper Commands

Initializes self-contained .kobean/ and wires agent discovery in the current repository.

Opens this interactive documentation web page in your default browser.

npx kobean-skills guide
Outputs the complete developer playbook and prompt cheatsheet directly in your terminal.

Engineering Doctrine & Precedence

  • Precedence Hierarchy: User Prompt > constitution.md > doctrine.md > Role Contract > Skill Runbook.
  • Single Task State: Beads (.beads/) is the exclusive source of truth. Never create tasks.md or progress.md.
  • Ponytail Economy: Write the smallest complete diff. Reuse project helpers > standard library > installed packages. Zero unrequested wrappers.
  • UI Hard Bans: No neon purple/blue AI-slop gradients, no 3-card marketing clichés, no missing :focus-visible or broken image placeholders.
  • Hard Completion Gates: Zero secrets (betterleaks), zero unmitigated CRITICAL AppSec findings, and 100% passing test suites.
